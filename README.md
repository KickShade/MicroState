# Crypto Market Microstructure Analysis

This project analyzes limit order book (LOB) data to discover liquidity patterns,
market anomalies, and microstructure signals invisible to standard price charts.

The project uses historical order book snapshots to:
- Study bid–ask depth and imbalance
- Detect liquidity gaps and pressure buildup
- Identify short-term market regimes
- Explore relationships between microstructure signals and price movement
